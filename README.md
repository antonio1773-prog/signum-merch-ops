# Signum Merch Ops

Sistema web interno para operar pedidos de merchandising de Signum.

## Que incluye

- Login demo con usuarios y contrasenas.
- Accesos por rol: vendedor, planeamiento comercial, taller, fabrica y direccion.
- Carga rapida de pedidos o presupuestos por vendedor.
- CRM simple de clientes con telefono y mail opcionales.
- Carga de imagen de logo o referencia en cada pedido.
- Catalogo de productos y dinamicas comerciales visibles para vendedores.
- Flujo operativo con aprobacion de planeamiento, sena del 50%, derivacion a taller o fabrica y fecha de entrega.
- Agenda de produccion e indicadores.

## Accesos demo

- Direccion: `direccion` / `admin`
- Vendedor: `mica` / `1234`
- Vendedor: `tomas` / `1234`
- Vendedor: `sofia` / `1234`

- Taller: `taller` / `1234`
- Fabrica: `fabrica` / `1234`

## Como correrlo

Abrir `index.html` en el navegador o servir la carpeta con cualquier servidor estatico.

## Nota

Esta version es un prototipo frontend con datos guardados en el navegador. Para produccion hace falta backend, base de datos, autenticacion real y almacenamiento de imagenes.
